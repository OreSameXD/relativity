# Текст для карточки портфолио

## Коротко (1–2 строки)
«Время относительно» — интерактивный 3D-сайт о теории относительности: главная листается как фильм, камера летит сквозь космос от главы к главе, в каждой главе интерактив с честной физикой, к каждому явлению статья с формулами и источниками.

## Описание (абзац)
Шесть явлений теории относительности показаны через интерактив простым языком: световые часы, парадокс близнецов, искривление пространства-времени, гравитационная линза и GPS. Главная страница — одна непрерывная 3D-сцена на React Three Fiber с собственными шейдерами и пост-эффектами (чёрная дыра реализована как пост-эффект тонкой линзы), камера управляется прокруткой через GSAP ScrollTrigger и Lenis. Статьи в MDX с формулами KaTeX, где числа в примерах пересчитываются ползунками интерактива. Все расчёты вынесены в чистые функции и покрыты тестами, каждый факт снабжён источником.

## Что подчеркнуть
- Архитектура Astro: текст статичен и индексируется, 3D и интерактивы — острова, общий store между островами.
- Один мастер-таймлайн GSAP ведёт камеру по кривой, snap к «кадрам» глав, ленивая загрузка глав, растворение соседних глав при перелёте.
- Кастомный пост-эффект гравитационной линзы (postprocessing Effect), купол туманностей на трёхмерном шуме, поток цветной пыли между главами.
- Честная физика: 1,75″ у края Солнца, 43″ в столетие для Меркурия, +38,4 мкс в сутки для GPS — всё считается кодом и проверяется vitest.
- Доступность и устройства: портретная компоновка, prefers-reduced-motion без полёта камеры, текстовая версия без WebGL, уровни качества с авто-понижением.
- SEO: свои title, description и OG-картинка (satori) у каждой страницы, sitemap.
