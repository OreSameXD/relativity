# «Время относительно» — обзорный сайт о теории относительности

## Язык
- **Все ответы, отчёты, комментарии к коммитам и документация — на русском.**
- Код, имена файлов, переменных и идентификаторы — на английском.

## Что это
Пет-проект для портфолио: кинематографичный 3D-сайт, где физика относительности объясняется через интерактив, плюс статьи с формулами (MDX + KaTeX).

## Стек
Astro + React-острова (React Three Fiber, drei, @react-three/postprocessing), TypeScript, GSAP + ScrollTrigger, Lenis, Motion (UI), MDX, remark-math + rehype-katex (формулы на сборке).

## Правила точности
- Физика и формулы считаются честно. Ничего не выдумывать: факты, даты, цифры — только с источником.
- Если не уверен — не писать или помечать «требует проверки».
- Где визуализация упрощена ради наглядности — мелкая пометка «упрощено».

## Порядок работы
Работа идёт этапами, после каждого этапа — стоп и отчёт пользователю:
1. План (docs/PLAN.md) → стоп.
2. Прототип интро и главы «Гравитационная линза» → скриншоты → стоп.
3. Статья-образец «Гравитационная линза» → стоп.
4. Остальные главы и статьи, по одной → стоп после каждой.

## Производительность и доступность
- Десктоп 60 FPS, ленивая загрузка тяжёлых глав.
- Мобильные: меньше частиц, без DoF, DPR ≤ 1.5, авто-упрощение при <30 FPS.
- prefers-reduced-motion: без полёта камеры, главы сменяются простым переходом.
- Без WebGL — текстовая версия с картинками.
- У каждой страницы свой title, description и OG-картинка.

## Скиллы
При работе использовать: gsap-* (особенно gsap-scrolltrigger), r3f-* (особенно r3f-shaders, r3f-postprocessing), motion, ui-ux-pro-max.
